## 1. สองค่าที่ต่างกันนิดเดียว

| token | ค่าใน `ui_tokens.h` | ค่าที่ PC ใช้ | ต่างกัน |

| `UI_OK` | `0x008B7A` | `0x178F7A` | ΔE ≈ 3 — ตาแทบแยกไม่ออก |

## 2. เพิ่มสีเส้นตัวที่ 4

ตอนนี้มี `UI_SERIES_1..3` ฝั่ง PC ใช้ค่าเดียวกันครบสามตัวแล้ว
เมื่อไรที่ P4 รองรับ 4 เซนเซอร์ ต้องใช้ค่านี้ให้ตรงกัน

```diff
 #define UI_SERIES_1      0x007C83   /* teal */
 #define UI_SERIES_2      0x8A5A00   /* น้ำตาลอมส้ม */
 #define UI_SERIES_3      0x4A5FA5   /* น้ำเงินอมม่วง */
+#define UI_SERIES_4      0x7A5A87   /* ม่วง — ตัวที่ 4 (ตรงกับ lab_theme.SERIES[3]) */
```

> **ทำไมเรื่องนี้สำคัญกว่าที่คิด:** ผู้ใช้ที่ดูกราฟบนจอแล้วหันมาดู PC

## 4. บั๊กเล็กที่เจอตอนอ่านโค้ด (ไม่เกี่ยวกับธีม)

`main/Kconfig.projbuild` — บล็อก `config EC_PROBE_ART_DETAILED` อยู่**นอก**
`menu "EC Monitor" ... endmenu`

```
    ...
endmenu                                  ← ปิด menu ตรงนี้

    config EC_PROBE_ART_DETAILED         ← แต่ตัวเลือกนี้ยังอยู่ต่อ
        bool "วาดหัววัดเป็นรูปเหมือน SEN0706"
```

ผลคือใน `menuconfig` ตัวเลือกนี้จะไม่โผล่ในเมนู `EC Monitor` แต่ไปลอยอยู่
ระดับบนสุดแทน แก้โดยย้าย `endmenu` ลงไปอยู่หลังบล็อกนั้น

อีกเรื่อง: `Kconfig.projbuild` ตั้ง `CONFIG_EC_UI_V2` เป็น `default n`
แต่ `sdkconfig` ที่ใช้อยู่จริงคือ `=y` และ `docs/SYSTEM.md` ก็เขียนว่า default `y`
ถ้าวันไหนมีคนลบ `sdkconfig` แล้ว build ใหม่ จะได้ UI ชุดเก่ากลับมาโดยไม่รู้ตัว
— ควรเปลี่ยน `default n` เป็น `default y` ให้ตรงกับความจริง
