## 1. จุดประสงค์

หยุดเวลาของซอร์สฝั่ง PC ที่ **ใช้งานจริงอยู่** ณ วันนี้ ก่อนจะเริ่มพัฒนา
แอปรุ่นใหม่แยกโฟลเดอร์ (`ec_measurement_station_pc`)

ก่อนหน้านี้โฟลเดอร์นี้ไม่มีระบบเวอร์ชันเลย มีแต่สำเนามือใน
`_backup_before_calreport\` และไฟล์ `.bak` ซึ่งย้อนกลับได้แค่จุดเดียว
และไม่มีทางรู้ว่า "ของจริง" คือไฟล์ไหน

**baseline นี้คือชั้น rollback ที่หายไป** — ไม่ว่างานฝั่งแอปใหม่จะไปทางไหน
คำสั่งเดียวก็กลับมาที่จุดนี้ได้

> ⚠️ commit นี้ **ไม่แก้พฤติกรรมของซอร์สแม้บรรทัดเดียว**
> เพิ่มเข้ามาแค่ `.gitignore` · `.gitattributes` · `BASELINE.md`

## 2. สิ่งที่ทำงานได้จริงและตรวจแล้ว ณ จุดนี้

### เก็บข้อมูล — `logger_3ec.py`

| | |
|---|---|
| เจ้าของพอร์ต CONTROL | process เดียว · CH340 `1A86:7523` |
| หาพอร์ตด้วย VID:PID | ตัด `303A:1001` (P4 NDJSON) และ `1A86:55D3` (P4 CH343) ออกเสมอ |
| CSV | `water_data\water_log_YYYY-MM-DD.csv` · `fsync` ทุกแถว |
| ต่อใหม่อัตโนมัติ | USB หลุดแล้วกลับมาเองภายใน ~5 วินาที |
| session | รายเซนเซอร์ เริ่ม/หยุดอิสระ · คีย์ `1/2/3` |
| `sample_id` | ผูกกับ session (จับตอนเริ่ม) ไม่ใช่ผูกกับรอบการรัน |
| `start_session()` | idempotent — เรียกซ้ำคืน `False` = "มีอยู่แล้ว" ไม่ใช่ "ล้มเหลว" |
| คาลิเบรต | คีย์ `[c]` → `C<n>,<uS>` ออกพอร์ตเดิม · ดูดข้อมูลต่อระหว่างทำ CSV ไม่ขาด |

**ตรวจแล้วด้วยข้อมูลจริง 24 ชั่วโมง (34,560 แถว):**

| | เดิม | หลังแยก report worker |
|---|---|---|
| `_close()` บล็อกลูปอ่าน serial | **13.64 s** | **0.00 s** |
| หยุด 3 session ติดกัน | 40.9 s | 0.0 s |

**ทดสอบ end-to-end ด้วย pty จริง + pyserial จริง ที่จังหวะจริง 2.5 วินาที:**
ช่องว่างระหว่างแถว 2.50 s ทุกแถว · แถวช้า 0 · แถวที่ timestamp กระจุก 0

### รายงาน — `report_jobs.py` + `report_3ec.py`

- worker เธรดเดียว · สร้างทีละใบตามลำดับ · ไม่แตะ serial ไม่แตะ CSV
- ปิดโปรแกรมแล้วรอเขียนไฟล์จนจบก่อน process จบ (กัน PDF ที่เขียนไม่จบ)
- รายงานล้มเหลวไม่ทำให้ logger ตาย และไม่กระทบ session อื่น
- PDF 9 หน้า + Excel ต่อ session · รายงานรวมตอนปิดรอบ

### หน้าจอ — `desktop_ui.py` v3.1 + `lab_theme.py`

- ธีม Clean Laboratory HMI ชุดเดียวกับจอ ESP32-P4
- 8 สถานะตรงกับจอ: `LIVE` `CHANGING` `STEADY` `STALE` `NO RESPONSE`
  `SENSOR FAULT` `DISABLED` `OFFLINE`
- รองรับ 1–4 เซนเซอร์ตาม mask · เซนเซอร์ที่ปิดไม่ขึ้นเป็น error และไม่มีแผงกราฟ
- กราฟไม่กะพริบและไม่ล้าง zoom ที่ผู้ใช้ตั้งไว้ (`set_data()` แทน `ax.clear()`)
- เปิด DPI awareness แล้ว — layout ไม่ถูกบีบบนจอที่สเกล 125%/150%
- ปรับความหนาแน่นตามความสูงหน้าต่างจริง: ยอมตัด event log ก่อน ไม่ตัดกราฟ
- **ไม่มีเลขสีดิบในไฟล์ UI เลย** — ทุกสีมาจาก `lab_theme.py`
- ตั้ง style ทีละ figure/axes ไม่แตะ `rcParams` ระดับ global
  ⇒ หน้าตาของรายงานจาก `report_3ec.py` ไม่เปลี่ยน

## 3. สิ่งที่ **ยังไม่มี** ณ จุดนี้

| | สถานะ |
|---|---|
| P4 bridge (NDJSON บน `303A:1001`) | **ยังไม่มีฝั่ง PC เลย** — ฝั่งจอพร้อมแล้ว |
| การรับ event `reading_saved` จากจอ | ยังไม่มี |
| การสังเกตการคาลิเบรตที่สั่งจากจอ | ยังไม่มี — `calibration_log.json` ยังไม่เคยถูกสร้าง |
| `active_mask` จริงจาก CONTROL | **ยังไม่มีช่องทาง** — `.ino` ยังเป็น `#define N_SENSORS 3` และไม่มี NVS |
| CSV v2 (4 เซนเซอร์ + seq + mask) | ยังไม่ทำ |
| คำสั่งจากจอมาที่ PC | ยังไม่ทำ (ตั้งใจ) |
| index/cache ของ CSV | ยังไม่มี — `read_range()` อ่านทุกไฟล์ทุกบรรทัดทุกครั้ง |

### ปัญหาที่รู้อยู่แล้วและยังค้าง

1. **schema ของ CSV ปนกันในโฟลเดอร์เดียว** — ไฟล์ `water_log_2026-08-05.csv`
   และ `2026-08-07.csv` มี header ของ `logger.py` รุ่นเก่า (7 คอลัมน์)
   แต่ข้อมูลข้างในเป็นแบบ 3 เซนเซอร์ เพราะ `logger.py` เขียนชื่อไฟล์รูปแบบเดียวกัน
2. **มี `__main__` ถึง 8 ไฟล์** — เคยทำให้รันไฟล์ผิดตัวโดยไม่รู้ตัวมาแล้ว
   บรรเทาด้วย `run_dashboard.bat` / `run_logger.bat` และ banner บอก path ตอนเปิด
3. `read_range()` โตเป็นเส้นตรงตามปริมาณข้อมูล (24 ชม. ≈ 0.8 วินาทีต่อครั้ง)
4. รุ่นเก่าที่ยังอยู่ในโฟลเดอร์: `logger.py` `report.py` `web_dashboard.py`
   `line_notifier.py` — ไม่ควรรันแล้ว โดยเฉพาะ `logger.py` (ข้อ 1)

## 5. ความเป็นส่วนตัวของข้อมูล

repo นี้ **ไม่มี** ข้อมูลห้องแล็บ ไม่มีค่าที่วัดได้จริง ไม่มีชื่อตัวอย่าง
ไม่มีโน้ตของผู้ทดลอง ไม่มีรายงาน และไม่มีความลับหรือรหัสผ่านใด ๆ

เก็บเฉพาะซอร์สโค้ด เอกสาร และสคริปต์ติดตั้ง — ดูรายการที่ถูกกันไว้ใน `.gitignore`

ภาพใน `docs\` เป็นภาพหน้าจอที่สร้างจาก **ข้อมูลจำลอง** ไม่ใช่ข้อมูลการทดลองจริง
