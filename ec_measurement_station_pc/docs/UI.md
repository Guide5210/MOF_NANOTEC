# หน้าจอ P1-B — ผู้อ่านอย่างเดียว

## ชั้นของโค้ด และเหตุผลที่แยกแบบนี้

```
app.py                 ประกอบทุกอย่าง + ลูป tick 1 วินาที
  ui/dashboard.py      หน้าต่างหลัก (Tk)
    ui/cards.py        การ์ดเซนเซอร์
    ui/chart.py        แผงกราฟ (Tk canvas + toolbar)
    ui/events.py       ตารางเหตุการณ์
    ui/diagnostics.py  หน้าต่างแยก
    ui/widgets.py      Card / Banner / Segmented / Button / Dot / KeyValue
  ui/view_model.py     ★ ตรรกะทั้งหมด — ไม่ import tkinter
  ui/series_painter.py ★ ตรรกะเส้นกราฟ — ไม่ import tkinter
  ui/lab_theme.py      token + นโยบายสถานะ + rcParams
  core/csv_source.py   อ่าน CSV ของ legacy แบบต่อยอด (read-only)
```

★ สองไฟล์นี้คือเหตุผลที่เงื่อนไขการยอมรับทั้งสี่ข้อทดสอบได้จริง
เครื่องที่รันเทสต์ไม่มี tkinter ด้วยซ้ำ — ถ้าตรรกะฝังอยู่ในวิดเจ็ต
เราจะเหลือแค่ "ดูแล้วโอเค" ซึ่งไม่ใช่หลักฐาน

## กฎการแสดงผลที่ห้ามละเมิด

| กรณี | ต้องทำ | ห้ามทำ |
|---|---|---|
| เซนเซอร์ถูกซ่อนบน HMI | ไม่วาดการ์ดเลย | วาดเป็น `0.0` หรือขึ้น error |
| จอ P4 หลุด | คงค่า mask ล่าสุด + ป้าย `P4 OFFLINE — showing last HMI selection` | รีเซ็ตเป็นครบทุกตัว / ซ่อนการ์ดทั้งหมด |
| ไม่เคยได้ mask จากจอเลย | แสดงครบทุกตัว **ไม่มีป้าย** | ใช้ป้ายเดียวกับกรณีจอหลุด |
| ผู้ใช้ zoom/pan | ขึ้น `HISTORY VIEW — LIVE FOLLOW PAUSED` (amber) และหยุด autoscale | เลื่อนกราฟตามข้อมูลใหม่จนผู้ใช้หาที่เดิมไม่เจอ |
| จอหลุดกลางคัน | ประวัติเหตุการณ์ยังอยู่ครบ | ล้างรายการ |
| ซ่อนเซนเซอร์แล้วเปิดกลับ | สีเส้นเดิมเป๊ะ | ปล่อยให้ prop_cycle เลื่อนจนสีสลับ |

## ลำดับความสำคัญของแถบแจ้งเตือน

มีได้ทีละอันเท่านั้น เรียงจากร้ายแรงที่สุด

1. `P4 BRIDGE ERROR — …` (แดง)
2. `PC LOGGER OFFLINE — ไม่มีใครกำลังเก็บข้อมูล` (แดง)
3. `P4 OFFLINE — showing last HMI selection` (เหลือง)
4. `HISTORY VIEW — LIVE FOLLOW PAUSED` (เหลือง)

แถบอยู่ในช่องที่จองไว้ใต้ header เสมอ ไม่ย้ายที่ตามลำดับการเกิดเหตุ

## dashboard กับ Diagnostics ต่างกันตรงไหน

| | ตอบคำถามของใคร | มีอะไร |
|---|---|---|
| dashboard | คนที่กำลัง **ทำการวัด** | ค่า EC · สถานะ · แนวโน้ม · เหตุการณ์ที่มีความหมาย |
| Diagnostics | คนที่กำลัง **ไล่ปัญหาระบบ** | boot_id · heap · queued · เฟรมพัง · event_id เต็ม |

ปนกันแล้วคนวัดจะเห็นตัวเลขที่ตีความไม่ได้เต็มหน้าจอ แล้วเริ่มไม่ไว้ใจ
ตัวเลขที่สำคัญจริง ๆ ที่อยู่ข้าง ๆ กัน

## ภาษาบนหน้าจอ

- **คำสถานะและชื่อ field ทางเทคนิค** — อังกฤษ ตรงกับ `monitor_state_text()`
  ของ P4 ทุกตัวอักษร และตรงกับชื่อ field ในโปรโตคอล
- **ประโยคอธิบาย / แถบแจ้งเตือน** — ไทย
- ตารางเหตุการณ์และ Diagnostics เป็นอังกฤษล้วน เพราะเป็นตารางที่ต้อง
  จัดคอลัมน์ให้ตรงกันและอ่านเทียบกับจอ
