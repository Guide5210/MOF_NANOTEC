# display_mask — ใครเป็นเจ้าของการเลือกเซนเซอร์

## สองคำที่ต้องไม่สับสน

| | คืออะไร | เจ้าของ | มีจริงยัง |
|---|---|---|---|
| `display_mask` | ผู้ใช้เลือก "จะแสดงตัวไหน" บนจอ | จอ P4 | ✅ |
| `active_mask` | CONTROL โพล Modbus ตัวไหนจริง | CONTROL | ❌ ยังเป็น `#define N_SENSORS 3` |

**การปิดการแสดงผลต้องไม่ทำให้หยุดเก็บ raw log** — ถ้าปิดแล้วหยุดเก็บด้วย
วันที่ผู้ใช้อยากย้อนดูข้อมูลจะไม่มีอะไรให้ดู และไม่มีทางกู้คืน

## สถานะการซิงก์

```
UNKNOWN ──hb แรกที่ใช้ได้──> FOLLOWING <──ผู้ใช้กด "ตามจอ"── OVERRIDE
   │                            │  ▲                            ▲
   │                     จอเงียบ│  │hb กลับมาค่าเดิม            │ผู้ใช้แก้ที่ PC
   │                            ▼  │                            │
   └────ค่าที่ cache ไว้────> STALE ─────ค่าต่างจากที่ PC ใช้──> CONFLICT
```

- **`OVERRIDE` ไม่เคยถูกทับ** — ผู้ใช้สั่งคงค่าไว้แล้ว hb ที่ตามมาไม่มีสิทธิ์เปลี่ยน
- **`CONFLICT` ไม่ตัดสินใจแทนคน** — แสดงทั้งสองค่าแล้วรอผู้ใช้กดเลือก
  การเลือกให้เองเสี่ยงกว่า เพราะผู้ใช้จะไม่รู้ว่าสิ่งที่เห็นไม่ตรงกับที่ตั้งไว้

## กฎการตีความค่า

| ค่าที่ได้ | ผล | เหตุผล |
|---|---|---|
| `255` (`0xFF`) | `None` — ไม่ถือว่าเป็นค่า | ค่าตั้งต้นใน `pc_bridge.c:91` ก่อนถูกเซ็ตจริง **ห้ามตีความเป็น 7** |
| `0` | ปฏิเสธ ใช้ค่าเดิมต่อ | mask ว่าง = ไม่แสดงอะไรเลย น่าจะผิดมากกว่าตั้งใจ |
| มีบิตนอก `0b0111` | ตัดบิตทิ้ง + เขียน log | P1 รองรับ 3 ตัว |

`effective()` ไม่เคยคืน `None` — ไม่รู้อะไรเลยให้แสดงครบทุกตัว ปลอดภัยที่สุด

## สิ่งที่บันทึกลง event log

`DISPLAY_MASK_INITIAL` · `DISPLAY_MASK_CHANGED` (มี `from`/`to`) ·
`DISPLAY_MASK_REJECTED` · `DISPLAY_MASK_OUT_OF_RANGE` · `P4_REBOOT`

ทั้งหมดเป็น `source: "pc"` — PC เป็นคนสังเกตเอง ไม่ใช่เฟรมที่จอส่งมา
