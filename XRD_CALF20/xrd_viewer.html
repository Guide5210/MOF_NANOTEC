What this changes

Peak fitting, Scherrer crystallite size, crystallinity, phase identification, the peak table and every export (CSV, Markdown, PDF) use only this window. Reference peaks outside it are excluded from phase scoring too, so a phase is never penalised for reflections you deliberately left out.

The 2θ range on the Display tab is independent: zooming the figure never moves a number. When the ROI is narrower than the view, it is shaded on the chart.

How notes are rendered

The PDF font (Helvetica) has no Thai glyphs, so notes are drawn to a canvas in the browser's own font stack and embedded as an image. Thai, English and mixed text all come out correctly, and long notes are paginated automatically.
